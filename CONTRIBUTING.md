# Contribuir a Bolty Switch

Gracias por tu interés en mejorar Bolty Switch.

Puedes colaborar mediante:

- Informes de errores reproducibles.
- Propuestas de funciones o mejoras visuales.
- Información sobre compatibilidad con Windows.
- Pull requests previamente acordadas con Zazen AI Studio.

La aceptación de una contribución no concede derechos sobre la marca, el personaje Bolty, los recursos visuales ni el resto del proyecto. Las modificaciones y versiones derivadas siguen sujetas al archivo [`LICENSE`](LICENSE).

No publiques contraseñas, tokens, datos personales, claves de API ni archivos privados en Issues o Pull Requests.
